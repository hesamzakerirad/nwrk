`nw` measures how your network reaches a destination and explains what the evidence shows. It runs on your machine and uploads nothing.

nw is in early development. Right now it can print its version and generate shell completions; the diagnostic commands arrive release by release. The [roadmap](https://github.com/hesamzakerirad/nwrk/blob/main/docs/ROADMAP.md) lists what each release adds, and the [specification](https://github.com/hesamzakerirad/nwrk/blob/main/docs/SPEC.md) explains the design.

Start with the install guide.
