`nw` measures how your network reaches a destination and explains what the evidence shows. It runs on your machine and uploads nothing.

nw is in early development. `nw diagnose <target>` investigates a destination across DNS, TCP, TLS and HTTP and explains what the evidence shows, with findings, hypotheses and next steps. `nw test` runs each of the four measurements on its own. More commands arrive release by release. The [roadmap](https://github.com/hesamzakerirad/nwrk/blob/main/docs/ROADMAP.md) lists what each release adds, and the [specification](https://github.com/hesamzakerirad/nwrk/blob/main/docs/SPEC.md) explains the design.

Start with the install guide.
